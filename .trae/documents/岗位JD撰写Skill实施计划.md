# 岗位JD撰写Skill - 实施计划

## 摘要

创建一份通用的岗位JD撰写Agent Skill，专门面向制造业甲方人事使用。Skill产出的结构化JD将作为提示词，喂给AI用于简历信息提取和匹配度评估。

## 需求分析

### 用户画像
- **使用者**：制造业甲方人事（新手为主）
- **使用场景**：制造业工贸一体公司，涵盖研发、生产、运营等全岗位类型

### 最终用途
生成结构化信息 → 作为提示词喂给AI → 提取简历文本内容 + 评估简历匹配度

### 核心设计原则
1. **简单直观**：新手也能快速上手
2. **标准结构化**：统一格式便于AI解析
3. **量化标准**：附带可量化的匹配标准

## 核心模块设计

### 标准JD结构（含标签）

```markdown
# 岗位名称

## 基础信息
- 部门：[部门名称]
- 岗位类别：[研发/生产/运营/职能等]
- 工作地点：[地点]
- 薪资范围：[范围，可选]

## 岗位职责
[按重要性排序，每条职责带行为标签]

## 任职要求

### 必须项 [必须]
- 学历：[学历要求] [必须]
- 经验：[年限要求] [必须]
- 专业：[专业要求，可选] [必须]
- 技能/证书：[硬性技能要求] [必须]

### 加分项 [加分]
- [软性优势条件] [加分]
- [稀缺经验/背景] [加分]

## 岗位亮点
[福利/发展/氛围等吸引力点]

## 量化匹配标准（供AI评估用）
{
  "must_match": {
    "education": "学历必须≥[要求]",
    "experience_years": "经验必须≥[N]年",
    "skills": ["技能1", "技能2"]
  },
  "bonus_points": {
    "skills": ["加分技能列表"],
    "experience": ["加分经验类型"]
  }
}
```

## 交互流程设计

### 输入方式
用户只需提供岗位基本信息，Skill引导式提问补充关键要素：

```
岗位名称：[输入]
所属部门：[输入]
岗位类型：[研发/生产/运营/职能]
工作地点：[输入]
```

### 引导式补充
- 核心职责是什么？（至少3条）
- 必须具备的硬性要求？
- 具备哪些条件会加分？
- 岗位有哪些吸引人的亮点？

## 量化标准模板

### 学历
| 标签 | 含义 |
|------|------|
| [必须] | 硬性门槛，不满足直接淘汰 |
| [加分] | 满足则加分，不满足不扣分 |

### 经验年限
- 精确到具体数字（如3年、5年）
- 可标注"及以上"

### 技能要求
| 标签 | 含义 |
|------|------|
| [必须] | 缺少该技能 = 不通过 |
| [加分] | 拥有该技能 = 加分项 |

## 假设与决策

1. **Skill类型**：Simple Skill（单文件流程，结构简单）
2. **依赖**：无外部API依赖，纯模板+结构化输出
3. **语言**：中文输出（用户明确是中文场景）
4. **使用门槛**：用户输入岗位基本信息即可，Skill引导补充细节
5. **量化标准**：提供默认量化模板，用户可灵活调整
