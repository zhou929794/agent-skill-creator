# 岗位JD生成器（AI专用版）

## 输入类型识别
- A：口语化描述（含部分要求）
- B：纯职责描述（无任职要求）
- C：极简输入（仅岗位名/缩写）
- D：招聘网站复制（格式散乱）

## 处理规则

### 规则1：提取关键词
提取：岗位名称、学历、经验年限、专业、技能、证书、行业、地点、薪资、管理规模

### 规则2：删除软技能
删除所有软技能描述（沟通能力、团队协作、学习能力、责任心、抗压能力、上进心等），不输出。

### 规则3：标准化表述
- "大专" = "专科", "高职"
- "本科" = "学士", "大学本科"
- "硕士" = "研究生"
- "SolidWorks" = "SW", "三维建模"
- "Pro/E" = "ProE", "Creo"

### 规则4：去重
删除重复的要求。

### 规则5：极简输入自动补充
当输入仅为岗位名/缩写时，使用预设规则自动补充常见要求（见"岗位预设规则"）。

### 规则6：模糊输入智能追问
当输入信息不足时，提供选项式追问：

```
请补充以下信息（可多选）：
1. 学历要求：[大专] [本科] [硕士]
2. 经验年限：[1-2年] [3-5年] [5年以上]
3. 技能要求：[从预设列表选择]
```

## 多岗位处理规则

当输入包含多个岗位时：
1. 拆分为独立岗位
2. 每个岗位使用预设规则自动补充
3. 批量输出，每个岗位独立完整

---

## 矛盾信息处理规则

当输入存在矛盾时：
1. 识别矛盾点
2. 在输出中标注矛盾
3. 取较宽松的条件作为必须项
4. 在JSON中添加notes字段说明

示例：
```
输入："本科以上，但其实大专也可以"
输出：学历=大专及以上（本科优先）
```
