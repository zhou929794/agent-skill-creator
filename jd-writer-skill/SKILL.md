# 岗位JD生成器（AI专用版）

## 输入类型识别
- A：口语化描述（含部分要求）
- B：纯职责描述（无任职要求）
- C：极简输入（仅岗位名/缩写）
- D：招聘网站复制（格式散乱）

## 处理规则

### 规则1：提取关键词
提取：岗位名称、学历、经验年限、专业、技能、证书、行业、地点、薪资

### 规则2：删除软技能
删除所有软技能描述（沟通能力、团队协作、学习能力、责任心等），不输出。

### 规则3：标准化表述
- "大专" = "专科", "高职"
- "本科" = "学士", "大学本科"
- "硕士" = "研究生"
- "SolidWorks" = "SW", "三维建模"
- "Pro/E" = "ProE", "Creo"

### 规则4：去重
删除重复的要求。

## 职责→技能映射规则

### 研发类
- 设计 → SolidWorks, Pro/E, Creo
- 量产导入 → APQP, PPAP, NPI
- 模具 → 模具设计, 注塑
- 专利 → 专利撰写

### 生产类
- 现场管理 → 5S, 精益生产, TPM
- 体系 → ISO9001, IATF16949

### 质量类
- SPC → SPC, Minitab
- FMEA → FMEA, DFMEA
- 体系 → ISO9001, IATF16949, 内审员

### 供应链类
- 采购 → 供应商管理, ERP
- 计划 → PMC, ERP, Excel
