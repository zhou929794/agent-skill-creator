本文档详细说明岗位JD各模块的撰写规范和最佳实践。

## 一、基础信息模块

### 规范要求

基础信息是JD的门面，需要清晰、准确、完整。

### 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 岗位名称 | 精确职位名称，不使用简称 | 产品研发工程师 |
| 所属部门 | 真实部门名称 | 研发中心 |
| 岗位类别 | 大类归类 | 研发/生产/运营/职能/销售 |
| 工作地点 | 具体城市/区域 | 深圳宝安区 |

### 选填字段

| 字段 | 说明 | 建议 |
|------|------|------|
| 薪资范围 | 薪酬区间 | 15-25K* |
| 招聘人数 | 该岗位的编制 | 2人 |
| 汇报对象 | 直接上级职位 | 汇报给研发经理 |

### 注意事项

1. **岗位名称要精准**：避免使用模糊的"专员""高级专员"等
2. **避免双重否定**：不用"不限"太多，显得没门槛
3. **薪资透明有利有弊**：建议在了解市场后再填写

## 二、岗位职责模块

### 撰写原则

**重要性排序**：第一条是最核心的工作，后面的重要性递减。

### 职责结构

每条职责建议采用"动词+内容+目标"结构：

```
[动词] + [具体工作内容] + [达成目标/产生价值]

示例：
- 主导新产品的设计开发，从概念设计到量产导入全流程跟进
- 建立并优化生产工艺标准，确保产品良率达到98%以上
- 协调研发与生产部门的沟通，推动项目按期交付
```

### 动词使用指南

| 类别 | 动词 | 适用场景 |
|------|------|----------|
| 决策类 | 主导、统筹、负责 | 核心职责、需要独立决策 |
| 执行类 | 执行、完成、跟进 | 日常操作性工作 |
| 协作类 | 协调、配合、参与 | 需要跨部门配合 |
| 管理类 | 管理、培训、考核 | 带团队、管理工作 |
| 优化类 | 优化、改进、提升 | 持续改进型工作 |

### 职责数量建议

| 岗位层级 | 建议职责数量 |
|----------|--------------|
| 基层岗位 | 4-6条 |
| 中层管理 | 5-8条 |
| 高层管理 | 6-10条 |

### 常见职责类型

**研发类**：
- 产品设计与开发
- 技术方案制定
- 样品试制与验证
- 技术文档编写
- 专利研究与申报

**生产类**：
- 生产计划执行
- 现场管理
- 质量控制
- 设备维护
- 精益改善

**运营类**：
- 供应链管理
- 仓储物流
- 采购执行
- 数据分析
- 流程优化

**职能类**：
- 制度流程建设
- 跨部门协调
- 数据报表
- 合规管理
- 预算管理

## 三、任职要求模块

### 分级标准

任职要求分为**必须项**和**加分项**两个层级。

### 必须项 [必须]

**定义**：硬性门槛，不满足直接淘汰的最低要求。

**包含内容**：

1. **学历要求**
   ```
   大专及以上 / 本科及以上 / 硕士及以上
   ```
   - 生产操作类：大专即可
   - 研发技术类：本科起步
   - 高级专家类：硕士优先

2. **经验要求**
   ```
   X年以上相关工作经验
   ```
   - 精确数字：1年/3年/5年/8年
   - 标注"相关"：同行业/同岗位
   - 避免模糊："丰富经验"不算数

3. **专业要求**
   ```
   XX类专业背景
   ```
   - 工科：机械、电气、材料、工业工程
   - 商科：工商管理、市场营销、财务
   - 文科：人力资源、汉语言文学

4. **技能/证书要求**
   ```
   熟练使用XXX / 持有XXX证书
   ```
   - 具体化技能：SolidWorks、Python
   - 可验证证书：PMP、CPA

### 加分项 [加分]

**定义**：不是必须项，但拥有会大大增加竞争力的软性优势。

**常见加分项类型**：

1. **稀缺经验**
   ```
   - 有跨境电商运营经验 [加分]
   - 主导过工厂新建项目 [加分]
   ```

2. **额外技能**
   ```
   - 具备数据分析能力(SQL/Python) [加分]
   - 有专利撰写经验 [加分]
   ```

3. **认证资质**
   ```
   - 持有六西格玛认证 [加分]
   - 有PMP认证优先 [加分]
   ```

4. **学历背景**
   ```
   - 985/211院校毕业优先 [加分]
   - 研究生学历优先 [加分]
   ```

### 加分项注意事项

1. **不要写太多**：控制在3-5条
2. **要有区分度**：加分项和必须项要有明显区分
3. **避免重复**：加分项不要再重复必须项的内容

## 四、岗位亮点模块

### 提炼方法

岗位亮点是吸引候选人投递的关键，需要真实、有吸引力。

### 常见亮点类型

| 类型 | 示例 |
|------|------|
| 薪酬福利 | 年终奖2-4个月、五险一金、商业保险、年度调薪 |
| 发展通道 | 每年2次晋升机会、管理/专业双通道 |
| 培训学习 | 专业技能培训、外部导师指导 |
| 团队氛围 | 90后占比70%、扁平化管理 |
| 公司优势 | 行业龙头、上市公司、稳定发展 |
| 工作生活 | 双休、不加班文化、交通便利 |
| 特殊福利 | 员工宿舍、免费三餐、年度旅游 |

### 亮点写作技巧

1. **具体化数字**
   ```
   ❌ 年终奖不错
   ✅ 年终奖2-4个月（根据绩效）
   ```

2. **突出差异点**
   ```
   ❌ 提供培训机会
   ✅ 每年万元学习基金，支持外部培训考证
   ```

3. **真实可信**
   ```
   ❌ 晋升空间大
   ✅ 2024年内部晋升率达35%
   ```

## 五、制造业专项考量

### 研发类岗位

**必须项重点**：
- 学历：本科及以上
- 行业经验：制造业背景优先
- 技能：专业工具使用（CAD/CAE）
- 认证：相关工程师职称

**加分项重点**：
- APQP开发流程经验
- 专利撰写能力
- 新产品导入经验

### 生产类岗位

**必须项重点**：
- 学历：大专起步（管理岗本科）
- 行业经验：制造业背景
- 管理体系：ISO体系基础
- 经验年限：5年以上管理经验

**加分项重点**：
- IATF16949体系经验（汽车行业）
- 精益生产项目经验
- 设备管理经验

### 质量类岗位

**必须项重点**：
- 证书：质量管理体系证书
- 工具：SPC/MSA/FMEA使用
- 经验：质量改善经验

**加分项重点**：
- 六西格玛绿带/黑带
- 供应商管理经验
- 客诉处理经验

### 职能类岗位

**必须项重点**：
- 学历：本科为主
- 工具：办公软件、ERP系统
- 经验：同岗位经验

**加分项重点**：
- 跨部门协调经验
- 项目管理经验
- 行业相关认证

## 六、不同岗位类型的JD差异

### 基层岗位

**特点**：门槛相对低，强调学习能力和发展潜力

**职责描述**：偏执行、偏操作
**要求描述**：年限要求低，可接受应届生
**亮点描述**：突出培训和发展机会

### 中层管理

**特点**：需要独当一面，带团队

**职责描述**：偏管理、偏决策
**要求描述**：年限要求明确，带团队经验
**亮点描述**：突出晋升通道和平台规模

### 专家/高级技术岗

**特点**：深度专业能力

**职责描述**：技术攻关、创新引领
**要求描述**：专业深度、行业认可
**亮点描述**：技术氛围、研究资源

## 七、标签使用示例

### 标签应用原则

1. **唯一性**：每条要求只能有一个标签
2. **准确性**：必须项用[必须]，加分项用[加分]
3. **可见性**：标签放在句末或用加粗标注

### 正确示例

```
- 本科及以上学历 [必须]
- 5年以上制造业经验 [必须]
- 熟悉ISO9001体系 [必须]
- 有精益生产项目经验 [加分]
- 持有PMP证书 [加分]
```

### 错误示例

```
❌ 本科及以上（有经验优先）  [必须]  ← 混淆
❌ 有驾照（会开车更好）        ← 缺少标签
❌ 熟练Excel（Word也要会）    ← 重复标签
```
