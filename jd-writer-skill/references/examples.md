## 七、使用指南

### 如何使用这些示例

1. **参考结构**：按照示例的结构撰写JD
2. **提取要素**：从示例中提取关键要素进行修改
3. **结合实际**：根据真实岗位需求调整职责和要求
4. **量化标准**：参考JSON格式生成量化匹配标准

### 快速修改示例

| 部分 | 修改建议 |
|------|----------|
| 基础信息 | 根据实际填写 |
| 岗位职责 | 参考示例动词，描述真实工作 |
| 任职要求 | 调整学历、经验年限和技能要求 |
| 岗位亮点 | 根据公司实际情况填写 |
| 量化标准 | 根据任职要求生成对应JSON |
