```

```

**输入类型**：A（口语化描述，含部分要求）

**Skill处理输出**：
```markdown

- 岗位类别：研发
- 工作地点：待补充
- 薪资范围：18-25K

| 维度 | 要求 | 简历匹配关键词 |

| 专业 | 机械 | 机械工程、机械设计 |
| 技能 | SolidWorks | SolidWorks、SW、三维建模 |
| 证书 | 无 | - |

### 优先项 [优先]
| 维度 | 要求 | 简历匹配关键词 |
|------|------|----------------|
| 行业 | 汽车电子 | 汽车电子、汽车行业 |

{
