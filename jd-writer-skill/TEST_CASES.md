# JD Writer Skill 真实测试用例集

## 说明
以下为真实场景中人事/用人部门常见的用人需求表述方式。

---

## 第一组：制造业常见需求（10个）

### Case-01: 研发工程师（口语化）
**真实输入**：
```
帮我们招一个做产品研发的，最好本科学历，机械专业，3-5年经验，会用SolidWorks， 有汽车电子经验更好，薪资18-25K
```

**场景特点**：相对完整，但口语化

---

### Case-02: 质量工程师（专业术语多）
**真实输入**：
```
QE工程师，IATF16949内审，SPC/MSA/FMEA，5年经验，有TS16949体系经验优先， 懂汽车行业更好
```

**场景特点**：专业术语多，表述精炼

---

### Case-03: 生产主管（管理属性）
**真实输入**：
```
车间主管，大专以上，5年现场管理经验，带过20-30人，会5S，懂精益生产， 有ISO9001体系经验
```

**场景特点**：管理属性明确

---

### Case-04: 极简需求（仅岗位名）
**真实输入**：
```
PMC
```

**场景特点**：极简，仅岗位缩写

---

### Case-05: 纯职责描述
**真实输入**：
```
【职责】
1.新产品从设计到量产导入
2.产品结构优化
3.样品制作跟进
4.技术问题解决
```

**场景特点**：纯职责，无任职要求

---

### Case-06: 矛盾/松动空间
**真实输入**：
```
机械工程师，本科以上，最好，但其实大专也可以，3-5年，其实2年也能考虑， 15-20K
```

**场景特点**：需求有弹性、有松动

---

### Case-07: 供应链岗位
**真实输入**：
```
采购，3年电子行业采购经验，会用SAP，能独立开发供应商，成本意识强， 有汽车行业供应商资源优先
```

**场景特点**：供应链类

---

### Case-08: 跨职能背景
**真实输入**：
```
工艺工程师，最好从QE或者制造工程转过来的，懂工艺，会看图纸， 5年经验，本科学历
```

**场景特点**：强调跨职能背景

---

### Case-09: 招聘网站粘贴
**真实输入**：
```
【任职要求】
1.大专及以上学历
2.3年以上工作经验
3.熟练使用CAD软件
4.有相关工作经验优先

【岗位职责】
1.负责产品图纸设计
2.负责技术文档整理
3.协助解决生产问题
```

**场景特点**：从招聘网站直接复制过来，格式散乱

---

### Case-10: 软技能主导
**真实输入**：
```
项目工程师，要有责任心，能扛事，沟通能力强，团队意识好， 会开车，能接受出差
```

**场景特点**：软技能描述多，硬技能不明确

---

## 第二组：特殊场景（5个）

### Case-11: 紧急招聘
**真实输入**：
```
急招！QE工程师，明天就要有人到岗！！！大专以上，3年经验， 懂SPC，有汽车行业经验优先，待遇可谈
```

**场景特点**：强调紧急性

---

### Case-12: 薪资明确
**真实输入**：
```
结构工程师，15-20K，13薪，年终奖2个月，五险一金，包吃住， 要求5年经验，本科，机械专业
```

**场景特点**：薪资福利明确

---

### Case-13: 多岗位需求
**真实输入**：
```
我们需要招4个岗位：
1.研发工程师（结构方向）
2.电子工程师（硬件）
3.QE工程师
4.生产班长
```

**场景特点**：一次多个岗位

---

### Case-14: 地域要求
**真实输入**：
```
仓库主管，要在沙井上班，能接受加班，大专以上，4年以上仓库管理经验， 有ERP经验，会用叉车优先
```

**场景特点**：明确地域要求

---

### Case-15: 应届生需求
**真实输入**：
```
研发助理工程师，应届生也可以，机械相关专业，会基础的软件， 学习能力强，有上进心
```

**场景特点**：明确接受应届生

---

## 第三组：模糊/矛盾场景（5个）

### Case-16: 极度模糊
**真实输入**：
```
招人，懂技术的，来车间
```

**场景特点**：极度模糊

---

### Case-17: 技术细节不明确
**真实输入**：
```
电气工程师，会用PLC，懂一些电气回路，会编程
```

**场景特点**：技术细节不明确（具体PLC型号、编程语言等）

---

### Case-18: 自相矛盾
**真实输入**：
```
主管级工程师，不要求带人，只要技术好，3-5年经验， 但要能带领项目
```

**场景特点**：描述矛盾（主管级 vs 不带人）

---

### Case-19: 行业经验不明确
**真实输入**：
```
做过相关行业的就行，不限
```

**场景特点**：不明确"相关"是什么

---

### Case-20: 年龄限制（敏感）
**真实输入**：
```
工程师，35岁以下，本科，3年以上
```

**场景特点**：包含年龄限制

---

## 测试原则
1. 真实场景为基础，尽量贴近实际
2. 覆盖制造业核心岗位
3. 包含正常、边界、特殊场景
4. 可直接用于测试验证
